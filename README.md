LibraTrack

Library Catalog & Circulation System

LibraTrack is a Java-based Library Catalog and Circulation System. The project will be developed progressively throughout the Java 2 course, with each new programming concept being added to the same codebase.

The system is designed to help manage library books, their availability, and the circulation of books within a library.

Purpose

The purpose of LibraTrack is to provide a simple system for managing a library catalog and circulation activities while applying the Java programming concepts learned throughout the course.

Main Features

Adding and managing books
Searching for books
Viewing the library catalog
Checking out books
Returning books
Managing library members
Handling book reservations
Tracking borrowing history
Development

LibraTrack will be developed step by step throughout the semester. Each task will introduce and apply a new Java concept while building on the existing program.

The project uses Git and GitHub to track the development history and progress of the system.
